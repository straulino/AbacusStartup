# AbacusStartup

A comprehensive toolkit repository containing multiple applications built with Abacus.AI and modern web technologies.

## 📁 Repository Structure

This repository contains the following projects:

### 1. [Startup Toolkit](/startup-toolkit)
A collection of tools for working with the Abacus.AI platform, featuring PDF reading and summarization capabilities powered by advanced AI models.

**Features:**
- PDF text extraction and AI-powered summarization
- Question answering on document content
- Batch processing capabilities
- Abacus.AI SDK integration

### 2. [HRFlow - HR App](/hr-app)
A modern HR web application for employee directory management and leave request handling with role-based access control.

**Features:**
- Employee directory with search and sort
- Leave request management system
- Role-based access control (Admin/Employee)
- Built with Next.js 14, PostgreSQL, and Prisma

## 🚀 Getting Started

Each project has its own README with specific setup instructions:

- **Startup Toolkit**: See [startup-toolkit/README.md](/startup-toolkit/README.md)
- **HR App**: See [hr-app/README.md](/hr-app/README.md)

## 📋 Prerequisites

- Python 3.8+ (for Startup Toolkit)
- Node.js 18+ (for HR App)
- PostgreSQL (for HR App)
- Abacus.AI API Key (for Startup Toolkit)
